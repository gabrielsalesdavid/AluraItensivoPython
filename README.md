## 🎯 O que você encontrará

### 1. **Fundamentos de Python** 📚
Documentação completa dos conceitos básicos necessários para programar em Python:

- **Tipos de Dados**: int, float, str, bool, None
- **Estruturas de Dados**: listas, tuplas, dicionários, conjuntos
- **Variáveis e Escopo**: nomenclatura, escopo local e global
- **Operadores**: aritméticos, comparação, lógicos, atribuição
- **Controle de Fluxo**: if/elif/else, while, for, break, continue
- **Funções**: definição, retorno, parâmetros, argumentos variáveis
- **Manipulação de Strings**: métodos, formatação, indexação, slicing
- **Tratamento de Erros**: try/except, finally
- **Entrada e Saída**: input, print, leitura e escrita de arquivos
- **Boas Práticas**: PEP 8, nomenclatura, comentários

👉 [Leia a documentação completa de Fundamentos](Fundamentos/Python_Fundamentos.md)

### 2. **Conceitos Avançados** 🚀
Técnicas profissionais e padrões para desenvolvimento avançado em Python:

- **POO**: Classes, herança, polimorfismo, encapsulamento
- **Decoradores**: Modificadores de função e classe
- **Geradores e Iteradores**: Implementação de iteradores eficientes
- **Compreensões**: List, dict e set comprehensions
- **Context Managers**: Uso de `with` e criação de gerenciadores
- **Tratamento Avançado de Exceções**: Exceções personalizadas
- **Type Hints**: Anotações de tipo para melhor documentação
- **Módulos e Pacotes**: Organização e importação de código
- **Paradigmas Funcionais**: Map, filter, lambda, closures
- **Otimizações**: Caching, slots, operações vetorizadas
- **Padrões de Design**: Singleton, Factory, Observer
- **Async/Await**: Programação assíncrona

👉 [Leia a documentação completa de Conceitos](Conceitos/Python_Conceitos.md)

### 3. **Exemplos Práticos** 💻
Scripts demonstrando aplicações reais de Python:

- **BuscaAcoesAno.py**: Previsão de preços usando Prophet

## 🚀 Começando

### Pré-requisitos

- Python 3.8 ou superior
- pip (gerenciador de pacotes Python)

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/gabrielsalesdavid/AluraItensivoPython.git
cd AluraItensivoPython
```

2. Crie um ambiente virtual:
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Mac/Linux
python3 -m venv venv
source venv/bin/activate
```

3. Instale as dependências:
```bash
pip install -r requirements.txt
```
